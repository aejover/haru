하루를 쓰다가 막히는 점, 고장 난 기능, 있으면 좋겠는 기능이 있다면 알려 주세요. 하나하나 읽고 반영하고 있어요.

문의하는 방법

GitHub에서 문의 남기기

GitHub 계정으로 하루 저장소의 Issues에 글을 남겨 주세요. 남긴 글은 공개되니, 이름·연락처·API 키 같은 개인정보는 적지 마세요.

문의를 보낼 때 함께 적어 주면 좋은 것

  • 어떤 화면에서, 무엇을 눌렀을 때 생긴 일인지
  • 쓰는 기기와 브라우저 (예: 아이폰 Safari, 갤럭시 Chrome, Windows Edge)
  • 화면에 뜬 오류 문구 (가능하면 스크린샷)

먼저 확인해 보세요

  • 기록이 사라졌어요 — 하루의 기록은 기기의 브라우저에 저장돼요. 다른 브라우저나 시크릿 창에서는 보이지 않아요. 백업 파일이 있다면 설정 → 데이터 → 백업 불러오기로 되살릴 수 있어요.
  • Claude 기능이 안 돼요 — 설정 → Claude에 API 키를 넣었는지, “연결 테스트”가 성공하는지 확인해 주세요.
  • 알림이 안 와요 — 브라우저 알림 권한을 허용했는지, 휴대폰 알림은 ntfy 앱에서 같은 주제를 구독했는지 확인해 주세요. 알림은 하루가 기기에서 열려 있을 때 보내져요.

사용법은 사용 가이드에 정리돼 있어요.
