하루는 가입도, 설치 파일도 없어요. 주소를 열면 바로 쓸 수 있고, 원하면 홈 화면에 앱처럼 설치할 수 있어요. 처음 쓰는 분이 알아 두면 좋은 네 가지를 정리했어요.

1. 열자마자 쓰기

하루를 처음 열면 홈 화면에 오늘 날짜와 시계, 날씨, 오늘 할 일이 보여요. 예시 할 일이 몇 개 들어 있는데, 눌러서 고치거나 오른쪽 ×로 지우면 돼요. 왼쪽 위 메뉴(≡)를 누르면 할 일, 목표, 루틴, 캘린더, 가계부 같은 탭으로 이동할 수 있어요.

무엇부터 할지 모르겠다면 이 순서를 추천해요.

  1. 할 일 탭에서 매일 하는 일(약 먹기, 운동) 두세 개를 “매일 반복”으로 넣어요.
  2. 건강 탭에서 어젯밤 잔 시간을 기록해요. 나이에 맞는 적정 수면 시간과 오늘의 에너지 곡선이 나와요.
  3. 루틴 탭 → 설정에서 추천 루틴 하나를 넣고 “시작하기”를 눌러 봐요.

2. 앱처럼 설치하기

하루는 PWA(Progressive Web App)라서, 앱 스토어를 거치지 않고 홈 화면에 설치할 수 있어요. 설치하면 주소창 없이 앱처럼 열리고, 인터넷이 끊겨도 열려요.

기기설치 방법
아이폰·아이패드Safari로 연 뒤 아래쪽 공유 버튼(네모에 화살표) → “홈 화면에 추가” → “추가”
안드로이드Chrome 오른쪽 위 ⋮ → “앱 설치” 또는 “홈 화면에 추가” (삼성 인터넷은 아래 ≡ 메뉴)
Windows·MacChrome이나 Edge 주소창 오른쪽의 설치 아이콘 → “설치”

3. 기록은 어디에 저장될까

하루의 기록은 운영자의 서버가 아니라 지금 쓰는 기기의 브라우저 안에 저장돼요. 정확히는 브라우저가 사이트마다 따로 주는 저장 공간(IndexedDB)이에요. 덕분에 가입이 필요 없고, 내 일기나 가계부가 다른 곳으로 나가지 않아요.

대신 알아 둘 점이 있어요.

  • 휴대폰과 PC의 기록은 기본적으로 따로따로예요. 같은 기록을 쓰려면 아래 4번처럼 QR로 연결하세요.
  • 시크릿(사생활 보호) 창에서는 창을 닫으면 기록이 사라져요.
  • 브라우저 설정에서 “사이트 데이터 삭제”를 하면 하루의 기록도 함께 지워져요.

4. 컴퓨터와 휴대폰을 QR로 연결하기

컴퓨터와 휴대폰에서 같은 기록을 쓰고 싶다면 설정 → 기기 연결 → 연결 QR 만들기를 누르고, 휴대폰 카메라로 화면의 QR을 찍으세요. 하루가 열리면서 바로 연결돼요. 휴대폰에 이미 기록이 있으면 “합치기”(두 기기 기록을 모두 남기기)와 “받기”(휴대폰 기록을 지우고 컴퓨터 기록으로 바꾸기) 중에 고를 수 있어요.

  • 연결한 뒤에는 어느 기기에서 바꿔도 자동으로 맞춰져요. 컴퓨터가 꺼져 있어도 휴대폰은 그대로 쓸 수 있고, 다음에 둘 다 열리면 서로의 변경이 합쳐져요.
  • 할 일, 메모, 일기처럼 항목마다 따로 합쳐서, 한쪽에서 추가한 것과 다른 쪽에서 고친 것이 모두 남아요.
  • 기록은 연결한 기기들만 가진 열쇠로 암호화해서 주고받아요. QR과 연결 코드는 그 열쇠라서 다른 사람에게 보여 주면 안 돼요.
  • 아이폰에서 홈 화면에 설치한 하루는 Safari와 저장 공간이 따로예요. 설치한 앱 안에서 설정 → 기기 연결에 연결 코드를 붙여넣어 연결하세요.

5. 백업하고 다른 기기로 옮기기

설정 → 데이터 → 백업 내보내기를 누르면 모든 기록이 담긴 파일(haru-backup-날짜.json)이 만들어져요. 메모에 넣은 사진과 녹음도 함께 들어가요. 이 파일을 다른 기기로 보낸 뒤, 그 기기의 하루에서 백업 불러오기를 누르면 그대로 옮겨져요.

한 달에 한 번, 혹은 중요한 기록을 많이 남긴 날에는 백업 파일을 만들어 클라우드 드라이브에 올려 두면 안심이에요.

6. Claude 기능 켜기 (선택)

일정표 사진 읽기, 녹음 요약, 영수증 읽기, 목표 나누기 같은 기능은 Anthropic의 AI인 Claude가 해요. 쓰려면 Anthropic 콘솔에서 API 키를 만들어 설정 → Claude에 넣고 “연결 테스트”를 눌러 확인하면 돼요.

  • 키는 내 브라우저에만 저장되고, Claude를 부를 때 Anthropic으로만 보내져요.
  • 사용한 만큼 요금이 키 주인에게 청구돼요. 짧은 요청은 대개 몇 원 수준이지만, 사진을 많이 읽히면 늘어나요.
  • 여러 사람이 쓰는 컴퓨터라면 다 쓴 뒤 “키 삭제”를 눌러 주세요.

Claude 키가 없어도 Claude를 쓰는 기능만 빠질 뿐, 나머지는 모두 그대로 쓸 수 있어요.
