# 하루

할 일, 캘린더, 뽀모도로, 메모, 일기, 식단, 문서 작업(워드·한글·엑셀·PPT), 유튜브 라디오를 한 화면에서 쓰는 개인 생산성 프로그램입니다. 모든 탭 오른쪽 아래에 Claude가 있어서 물어보거나 일을 시킬 수 있어요.

## 실행

1. [Node.js](https://nodejs.org)를 설치합니다 (이미 있으면 건너뛰기).
2. 이 폴더의 `start.bat`을 더블클릭합니다. 처음에는 필요한 파일을 설치하고, 브라우저에서 `http://localhost:5500`이 열립니다.
3. Chrome이나 Edge 주소창 오른쪽의 **앱 설치** 아이콘을 누르면 별도 창의 프로그램처럼 쓸 수 있어요.

창을 닫아도 서버(검은 창)가 켜져 있으면 독촉 알림과 일정 알림이 계속 갑니다.

## 휴대폰에서 쓰기

`start.bat`을 실행하면 번호를 고르는 화면이 나와요 (고른 번호는 다음에도 기억해요).

| 번호 | 쓰는 곳 | 특징 |
|---|---|---|
| 1 | 이 컴퓨터에서만 | 기본값 |
| 2 | 같은 Wi-Fi의 휴대폰 | 설정 없이 바로 됨. https가 아니라서 휴대폰에서 녹음·받아쓰기·앱 설치는 안 되고, 같은 Wi-Fi의 누구나 주소를 알면 접속할 수 있어요. |
| 3 | 어디서나 (Tailscale, 추천) | 컴퓨터와 휴대폰에 Tailscale을 설치하고 같은 계정으로 로그인해 두면, 하루가 알아서 `tailscale serve`를 실행해요. 내 기기만 접속할 수 있고 https라서 모든 기능이 돼요. 처음 한 번은 안내되는 링크에서 HTTPS 사용을 켜야 해요. |

2번이나 3번으로 켜면 검은 창과 앱 화면에 휴대폰용 주소가 뜨고, **설정 → 휴대폰에서 열기**에서 QR 코드로 바로 열 수 있어요.

### 휴대폰에 앱으로 설치

휴대폰에서 https 주소(3번 Tailscale)를 연 다음:
- **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome · 삼성 인터넷)**: ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

홈 화면의 하루 아이콘으로 열면 주소창 없이 앱처럼 전체 화면으로 열려요. 기록은 컴퓨터에 하나로 저장되고, 컴퓨터와 휴대폰에서 바꾼 내용은 서로 곧바로 반영돼요. 컴퓨터에 연결할 수 없을 때는 무엇을 확인할지 알려 주는 화면이 떠요.

## GitHub Pages로 열기

앱 화면은 **https://aejover.github.io/haru/** 에도 올라가 있어요. 기록·Claude·알림은 여전히 내 컴퓨터(start.bat 3번, Tailscale)를 통해 동작해서, 컴퓨터가 켜져 있고 Tailscale로 연결된 내 기기에서만 내 기록이 보여요.

- 처음 열 때는 컴퓨터의 **설정 → 휴대폰에서 열기**에 있는 GitHub Pages QR로 여세요. 컴퓨터 주소가 자동으로 연결돼요.
- Chrome이 "로컬 네트워크의 기기에 액세스" 권한을 물으면 **허용**을 눌러 주세요.
- 코드를 고친 뒤 다시 배포하려면: `git subtree split --prefix public main`으로 만든 커밋을 `gh-pages` 브랜치로 올리면 돼요.

## 처음 한 번 설정 (설정 탭)

| 기능 | 필요한 것 |
|---|---|
| Claude (비서, 문서 AI 모드, 이미지 캘린더 읽기, 녹음 요약, 감정 추천, 식단 피드백, 롤모델 추천) | [Claude API 키](https://console.anthropic.com/settings/keys). 키는 `data/config.json`에만 저장됩니다. 기본 모델은 Claude Opus 5.5이고, 설정에서 Sonnet 5.5 · Haiku 5.5로 바꿀 수 있어요. 사용량만큼 요금이 나갑니다. |
| 휴대폰 알림 (독촉, 일정 당일 아침 브리핑) | 휴대폰에 무료 앱 **ntfy** 설치 → 설정에서 주제 이름 만들기 → 앱에서 같은 주제 구독 |
| 홈 화면 새 메일, 유튜브 내 구독·재생목록·좋아요·검색 | Google Cloud의 OAuth 클라이언트 ID (설정 탭에 단계별 안내가 있어요) |
| 날씨 | 필요 없음 (Open-Meteo). 지역은 설정에서 바꿀 수 있어요. |

## 탭 구성

- **홈**: 시계, 날씨(비·눈 예보 표시), 새 메일, 동기부여 문구(직접 편집), 오늘·이번 달·올해 진행률, 오늘 할 일·루틴 ⇄ 옆으로 넘기면 캘린더
- **메모장**: 텍스트, 녹음(말하는 동안 자동 받아쓰기 → Claude 요약), 링크, 이미지, 파일. 저장하면 **펜**으로 메모 위에 그릴 수 있어요.
- **캘린더**: 일정·할 일·루틴. 달력 위에 이미지(학사일정, 근무표 사진)를 넣으면 Claude가 읽어서 일정으로 넣어 줍니다.
- **뽀모도로**: 다른 탭에 가도 계속 돌아가고, 끝나면 알람. 집중·휴식 시간 설정, 오늘 집중 시간은 오른쪽 위에 표시
- **유튜브 · 라디오**: 링크 재생, 계정 연동 시 구독·재생목록·좋아요·검색. 라디오 모드는 화면 없이 소리만, 다른 탭에서도 계속 재생. "그만 보기" 알람(켜기/끄기, 간격 설정)
- **문서 작업**: 워드·한글·엑셀·PPT. 일반 모드(직접 편집)와 AI 모드(Claude에게 말하면 문서에 반영, 이미지·PDF 첨부 가능)
- **오늘 할 일**: 매일 vs 오늘만, 일반 vs 독촉. 독촉은 당일엔 할 때까지 반복, 밀리면 다음 날 3번 · 다다음 날 5번 · 3일째부터 10번
- **일기**: 제목·날짜·감정(Claude 추천)·오늘의 평가 5단계, 사진·영상, 월간 통계, 일기 캘린더, 1년 전 오늘
- **식단**: 신체 정보 → 기초대사량·TDEE·목표 칼로리와 영양소, 나만의 음식·레시피, 끼니 기록, 식습관 피드백
- **커리큘럼**: 오늘 vs 어제, 이번 주 vs 지난주(월요일 리포트), 집중 시간 대시보드
- **레벨 · 티어 · 전적**: 기능을 쓸수록 경험치 → 레벨. 어제보다 더 하면 승리(티어 상승), 지난주를 이기면 크게 상승

## 알아 둘 점

- 데이터는 모두 이 컴퓨터의 `data/` 폴더에 저장됩니다 (`state.json`, 사진·녹음은 `files/`). 설정 탭에서 백업 파일로 내보낼 수 있어요.
- 서버는 이 컴퓨터(localhost)에서만 열립니다. 휴대폰으로는 앱 화면이 아니라 ntfy 알림을 받습니다.
- 받아쓰기는 Chrome·Edge에서만 동작합니다 (인터넷 필요).
- 한글(.hwp) 형식으로 직접 저장할 수는 없어서, 한글에서 열 수 있는 .doc로 저장합니다. 엑셀은 .xlsx, PPT는 .pptx로 저장돼요.
- 일부 유튜브 영상은 채널 설정 때문에 외부 재생이 막혀 있어요.
